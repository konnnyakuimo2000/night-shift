# NIGHT//SHIFT — ITサポート（ヘルプデスク）問題一覧（案）

最終更新: 2026-10-04 ／ 状態: **検討中**（A1・A2 は実装済み）

ITサポートの問い合わせ（二択・リモート操作）は、**IPA（情報処理推進機構）の情報処理技術者試験の過去問題**を参照して作る。
使う試験区分:
- **ITパスポート試験** — 基本的な対応
- **情報セキュリティマネジメント試験** — 詐欺の手口・内部不正・インシデント対応など、より実務的な場面
- **基本情報技術者試験** — ネットワークの仕組み（DHCP・DNS・ping）など技術的な内容。主に**リモート操作**の問題に使う
- **応用情報技術者試験** — 攻撃の仕組み（C&Cサーバー・水飲み場型攻撃）、証拠保全、バックアップの方式など。**後半（第3〜4週）**の難しい問題に使う

## 0. 出典の扱い（IPA の方針）
- IPA が公表している過去問題は、**許諾・使用料なしで使える**。ただし**出典の明記**が必要（年度・期・試験区分・問番号）。**一部を改変した場合はその旨も書く**。（IPA「試験に関するよくある質問」より）
- このゲームでは、過去問題を**そのまま出題しない**。問題が問うている「正しい対応」を、1998年の社内の問い合わせ（社員のセリフ）に**作り直して**使う → すべて「（改変）」と書く。
- 出典の表示場所:
  1. 対応した後、問い合わせの記録に **【参考】解説＋出典** を表示（実装済み: `HelpDeskDefinition.explanation` / `sourceNote`）。
  2. タイトル画面の「クレジット」に、参考にした過去問題の一覧を載せる（未実装）。
- 1998年の設定に合わせて言葉を置き換える（例: USBメモリ → フロッピーディスク／MO、Webサービス → 会員サイト）。

#### 解禁（ランダム）
- Y1〜Y12 は、**ゲームを始めるたびに解禁日をランダムに決める**（DAY8〜DAY25 の間。決めた日は保存し、やり直しても変わらない）。
  - 同じ日に解禁されるのは2問まで。
  - ただし、対になる「いいえ」の問題（例: Y3 と A3）より**前に**解禁されることもある。どちらが先に来るかはプレイごとに違う。
- 1夜の二択（1〜2問）のうち、およそ **4割が「はい」、6割が「いいえ」**になるように選ぶ（毎晩どちらが来るか読めないようにする）。
- 同じ問題は30日間で2回まで（A と同じ）。

#### 回答の表示
- すべての二択を、**「はい／いいえ」＋理由**の形にそろえる（A1〜A22 も同じ形に書き直す）。
  - 例（A3）: 「いいえ。再起動せず、すぐLANケーブルを抜いてください」／「はい。再起動して様子を見てください」
  - 例（Y3）: 「はい。すぐ抜いて、電源はそのままにしてください」／「いいえ。まず再起動して様子を見てください」
- 「はい」と「いいえ」の並び順は毎回ランダム（今の二択と同じ）。
- 間違えた場合の影響: 「はい」が正解の問題で「いいえ」と答えると、社員が正しい対応をやめてしまう（例: Y3 → 再起動して痕跡が消え、V3 NIGHTCRY が広がる／Y11 → 退職者のIDが残り、T6 が起きる）。

## 2. リモート操作（TYPE B）

リモートデスクトップで社員のPCを操作して直す。研修の R1・R2 は一般的なトラブル（出典なし）。本番では**セキュリティの初動対応**を IPA の過去問題から作る。

### 簡単にするためのルール
- **1問 = 開く画面は1つ、操作は1〜2回**（チェックを1つ入れる・ボタンを1つ押す・項目を1つ選ぶ）。
- 文字やアドレスを**手で入力させない**（選ぶ・押すだけ）。
- どこを触ればいいかは、マニュアルの「ITサポート」のページに**画面の図で示す**（研修の R1・R2 と同じ形式）。
- 「やってはいけないこと」は1つだけにする（多くの場合「再起動」）。

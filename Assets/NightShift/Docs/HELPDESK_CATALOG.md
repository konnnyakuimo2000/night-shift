# NIGHT//SHIFT — ITサポート（ヘルプデスク）問題一覧（案）

最終更新: 2026-10-04 ／ 状態: **検討中**（A1・A2 は実装済み）

ITサポートの問い合わせ（二択・リモート操作）は、**IPA（情報処理推進機構）の情報処理技術者試験の過去問題**を参照して作る。

## 0. 出典の扱い（IPA の方針）
- IPA が公表している過去問題は、**許諾・使用料なしで使える**。ただし**出典の明記**が必要（年度・期・試験区分・問番号）。**一部を改変した場合はその旨も書く**。（IPA「試験に関するよくある質問」より）
- このゲームでは、過去問題を**そのまま出題しない**。問題が問うている「正しい対応」を、1998年の社内の問い合わせ（社員のセリフ）に**作り直して**使う → すべて「（改変）」と書く。
- 出典の表示場所:
  1. 対応した後、問い合わせの記録に **【参考】解説＋出典** を表示（実装済み: `HelpDeskDefinition.explanation` / `sourceNote`）。
  2. タイトル画面の「クレジット」に、参考にした過去問題の一覧を載せる（未実装）。
- 1998年の設定に合わせて言葉を置き換える（例: USBメモリ → フロッピーディスク／MO、Webサービス → 会員サイト）。

## 2. リモート操作（TYPE B）

リモートデスクトップで社員のPCを操作して直す。研修の R1・R2 は一般的なトラブル（出典なし）。本番では**セキュリティの初動対応**を IPA の過去問題から作る。

| ID | 解禁 | 問い合わせ（社員） | やること（解決の条件） | やってはいけないこと | 出典（すべて改変） |
|---|---|---|---|---|---|
| R1 ✅ | DAY5 | インターネットにつながらない | Wi-Fi をオンにする | — | （一般的なトラブル。出典なし） |
| R2 ✅ | DAY7 | 印刷できない | 印刷キューの一時停止を解除する | — | （一般的なトラブル。出典なし） |
| R3 | DAY9 | 社内の無線LANでWebを見ていたら、ブラウザが急に終了し、知らないファイルができた | **Wi-Fi を切って**PCをネットワークから隔離 → 「対応しました」と報告（情報システム部へ引き継ぎ） | 再起動する／定義ファイルの更新だけして済ませる／Wi-Fi を切らずに調べ続ける | 令和4年度 ITパスポート試験 問100 |
| R4 | DAY11 | 「修正プログラムが3件あります」と出たまま放ってある | 修正プログラム（更新）を**すべて適用**して再起動 | 「後で」を押して閉じる | 平成28年度 秋期 ITパスポート試験 問59 |
| R5 | DAY14 | 席を離れている間に、誰かがPCを触った気がする | **スクリーンセーバーのパスワード**を有効にし、待ち時間を **10分以下**にする（クリアスクリーン） | パスワードなしのスクリーンセーバーのまま | 令和5年度 ITパスポート試験 問90（選択肢エ） |
| R6 | DAY17 | 請求書の文書を開いたら、PCの動きがおかしい | ネットワークから切り離す → タスクマネージャーで**見慣れないプロセス**を確認して報告（終了させない＝痕跡を残す） | 再起動する／プロセスを片っ端から終了する | 令和2年度 秋期 ITパスポート試験 問58、平成29年度 秋期 ITパスポート試験 問94 |
| R7 | DAY19 | 部署の共有ファイルのバックアップを取っておきたい | 外付けの記録媒体（MO）へバックアップ → **取り外して**（ネットワーク・PCから切り離して）保管 | バックアップ先をつなぎっぱなしにする | 令和7年度 ITパスポート試験 問92、令和4年度 ITパスポート試験 問56 |

- R3 は研修の R1（Wi-Fi を**オン**にして直す）の**逆**。「つながらない」を直してきたプレイヤーが、「切るのが正解」の場面に出会う。
- R3・R6 で**再起動すると失敗**（「メモリやログに残った痕跡が消える」という IPA 過去問の解説の考え方を使う）。
- R6 は V1〜V4 の感染と連動させる（実際に感染している場合、見慣れないプロセスの名前が V のウイルスになっている）。

### 必要になるPCの状態（`VirtualPCState` に追加）
| キー | 使う問題 | 内容 |
|---|---|---|
| `Rebooted` | R3, R4, R6 | 対応中に再起動したか |
| `PendingPatches` | R4 | 未適用の修正プログラムの数 |
| `ScreenLockEnabled` / `ScreenLockMinutes` | R5 | スクリーンセーバーのパスワード・待ち時間 |
| `SuspiciousProcessReported` | R6 | 見慣れないプロセスを報告欄に書いたか |
| `BackupDone` / `ExternalMediaConnected` | R7 | バックアップしたか・外部媒体がつながったままか |
- リモートデスクトップに追加するアプリ: 「修正プログラムの更新」「画面のプロパティ（スクリーンセーバー）」「バックアップ」。

## 3. 実装メモ
- `HelpDeskDefinition` に `explanation`（解説）と `sourceNote`（出典）を追加済み。二択は回答後、リモートは解決後に【参考】として表示。
- A3〜A11・R3〜R7 は DAY8 以降の実装で追加する（`minimumDay` / `maximumDay` を設定し、ランダムに出す）。
- タイトル画面の「クレジット」に、出典の一覧（この文書の出典欄）を表示する。

## 4. 決めること
1. 二択を3択以上に増やすか（今は二択のまま）
2. 間違えたときに、解説を詳しく出すか（今は回答の後に短い解説だけ）
3. 情報セキュリティマネジメント試験・基本情報技術者試験の過去問題も使うか（今は ITパスポート試験のみ）

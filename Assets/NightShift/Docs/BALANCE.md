# NIGHT//SHIFT — ゲームバランス検証（DAY8〜30）

最終更新: 2026-10-04 ／ 方法: 自動シミュレーション（`Tests/EditMode/BalanceSimulator.cs`）

腕前の違う3人のプレイヤー（上級・平均・初心者）に DAY8〜30 を自動で遊ばせ、仕事量・期限切れ・被害・ランク・給与・購入・結末を集計した。
プレイヤーの速さは実時間（秒）で定義し、ゲーム内の時計の速さで換算している。

| 腕前 | 要求1件 | 正答率 | 二択 | リモート | 攻撃に気付くまで／確率 | 偽メールに引っかかる |
|---|---|---|---|---|---|---|
| 上級 | 8秒 | 97% | 8秒 | 35秒 | 5分／90% | 2% |
| 平均 | 14秒 | 90% | 14秒 | 60秒 | 10分／65% | 10% |
| 初心者 | 22秒 | 80% | 22秒 | 90秒 | 20分／35% | 25% |

## 調整前の問題（1回目）
- 上級者でも30日目に **倒産（END2）** か **全責任（END1）**。会社の信用が毎晩 平均 −7 で、23夜で 0 になっていた。
- DAY28〜30 の要求が同時発生込みで 48〜54 件。上級者でも期限切れが 13〜14 件。
- 平均的な人は DAY20 以降、1夜あたり 50% で致命的な被害（ゲームオーバー GO2）。
- 偽メールが毎晩のように来て、自分のIDの被害2回で即ゲームオーバー（GO3）。
- **バグ**: 管理者乗っ取り（T10）の「致命的」判定が、要求を許可していなくても停電が起きただけで成立していた。

## 調整した内容
| 項目 | 前 | 後 |
|---|---|---|
| 時計の速さ（本番） | 1.5秒/分（1夜 約9分） | **1.8秒/分（1夜 約11分）** |
| 接続要求の期限 | 22分 | **28分** |
| 1夜の要求数 | DAY8: 15 → DAY30: 30 | **DAY8: 14 → DAY30: 24** |
| 同時に重なる確率 | 0.15〜0.35 | **0.12〜0.25** |
| 攻撃の起きる確率（初登場の日以外） | T5 0.5／T7 0.6／T9 0.5／T10 0.45／T11 0.4 など | **T5 0.35／T7 0.4／T9 0.35／T10 0.3／T11 0.25／T3 0.6** など |
| 自律型攻撃AIの再挑戦 | 6回 | **4回** |
| 身代金ウイルスの手がかり | ログのみ | ＋**ファイルサーバー監視の警告**（書き込み急増） |
| 会社の信用 | 被害 −8、期限切れ等 −1/件、被害ゼロ +2、S +2 | **被害 −2（最大3件）、期限切れ等 4件で −1、被害ゼロ +2、ランク S+3／A+2／B+1／D−1** |
| GO2 の不正許可の上限 | 1夜 3件 | **4件** |
| GO3（自分のIDの被害） | 2回目 | **3回目**（1回目 警告・2回目 最終警告） |
| T10 の致命的判定 | 停電で成立（バグ） | **許可した かつ 停止しなかった場合のみ** |

## 調整後の結果（30日間の通し、各3回）
| 腕前 | ツール | 結末 |
|---|---|---|
| 上級 | 買わない | END4 引き抜き ×2、END6 契約更新 ×1（信用 92〜100） |
| 上級 | 買う | END4 引き抜き ×2、END6 契約更新 ×1（ツール10個・残金 約¥2万） |
| 平均 | 買わない | 倒産・GO2・GO3（ツールなしでは厳しい） |
| 平均 | 買う | END6 契約更新 ×2（信用 34〜47）、倒産 ×1 |
| 初心者 | どちらも | DAY13〜23 でゲームオーバー（GO1 契約打ち切り・GO2） |

### 狙いとの照らし合わせ
- 上級者は良い結末で完走できる → **OK**
- 平均的な腕前は「ツールを買えば完走できる、買わなければ厳しい」 → ツールの価値がはっきり出ている。**OK**
- 初心者は途中で終わりやすい。ゲームオーバー後に「その夜から／週の初日から」やり直せるので、上達しながら進む想定。
- 全部のツールは買えない（上級者でも約¥2万残し、AI と 2台目のモニターは買えない） → **狙いどおり**

## 今後の検証
- シミュレーターの「腕前」は推定値。実際に遊んだ人の速さ・正答率で置き換えると精度が上がる。
- 実行方法: Unity の Test Runner で `BalanceSimulator.WriteBalanceReport` を実行（または `-testFilter NightShift.Tests.BalanceSimulator.WriteBalanceReport`）。結果は `Logs/BalanceReport.md`。

# NIGHT//SHIFT — 朝のネットニュース（案）

最終更新: 2026-10-04 ／ 状態: **検討中**

DAY8 から、毎日の始まりに**ポータルサイトのニュース画面**を最初に表示する。
その夜に出てくる**脅威の存在**と**対処のヒント**を、世の中のニュースとしてそれとなく伝える。

---

## 1. 位置付け
- 表示のタイミング: **前日の評価画面 → ［ニュース］ → タイムカード → メールボックス**。
  - 設定: 主人公が出勤前に自宅のPCでニュースを見ている。表示の前に**ダイヤルアップ接続**の演出（「ピーヒョロロ…」の接続音と「接続中…」のダイアログ。2回目以降は短く、スキップできる）。
- **読むのは任意**（業務開始の条件にはしない）。ただし、ヒントを読み逃すとその夜が難しくなる。
- 閉じるボタン: ［接続を切って出勤する］。
- 研修期間（DAY1〜7）は表示しない（業務メールで十分なため）。DAY8 の初回だけ、業務メールに「今日から世の中のニュースにも目を通しておくように」と一言入れる。

## 2. デザイン（1998年のポータルサイトのパロディ）
- 当時の大手ポータルサイトのニュース面を**パロディ**にする。サイト名は架空の **「YAHHO! NEWS」**（ヤッホー！ニュース）。
  - **本家のロゴ・配色・書体はそのまま使わない**。「白地に横に長いロゴ、検索窓、青い下線付きリンク、カテゴリのタブ、小さな NEW アイコン」という**当時のポータルの雰囲気だけ**を借りる。
- ブラウザは架空の旧式ブラウザ「**NetVoyager 3.0**」の画面（戻る・進む・中止・更新・ホームのボタン、アドレス欄、読み込み中に回るロゴ、下のステータスバー「ドキュメント: 完了」）。

- **〈注目記事〉**（その夜の脅威のヒント）は最初から開いた状態で表示。ほかの見出しはクリックすると本文が開く。
- 見出しは5〜6本: 注目記事1本＋前夜の結果の記事（§4）＋息抜きの記事（芸能・スポーツ・天気など、すべて架空）。
- 文字は読みやすさ優先（メールと同じフォント・サイズの基準。小さすぎる文字にしない）。

  - 業務の画面の名前（「接続監視」など）は出さず、世の中の言葉で言う（例: 「接続元の住所（IPアドレス）が本人の端末と合うか」）。

## 4. 前夜の結果の記事（毎日変わる）
- 前夜の結果によって、自分の会社（架空の社名: **新都物産** ※仮）の記事が載る。

| 前夜の結果 | 記事の例 |
|---|---|
| 被害ゼロ・ランク S/A | （載らない。平穏な夜は記事にならない）→ 株価がわずかに上がる |
| 被害あり（情報漏えい・改ざん・感染） | 「新都物産でシステム障害 原因を調査中」「新都物産、顧客情報流出の可能性」 |
| 公開Webの改ざん（V2） | 「新都物産のホームページ、意味不明の文字に」（スクリーンショット付き） |
| ブラックアウト（V5） | 「都内のオフィスビルで深夜に停電」 |
| ゲームオーバーの警告段階 | 「新都物産、夜間のシステム管理を外部委託へ検討」（契約打ち切りの予感） |

- 右側の**株価**は**会社の信用**（ENDINGS.md）に連動して上下する（信用の数値そのものは見せない）。
- 信用が 30 以下になると「大口取引先が契約見直し」「株価急落」などの記事が出る（倒産エンドの予告）。

## 5. 息抜きの記事・広告（世界観）
- 1998年らしい架空の話題: 「2000年問題まであと○日」、新しいゲーム機の発売、ポケベルから携帯電話への乗り換え、サッカーの大会、ドラマの視聴率など（すべて架空の名前）。
- **広告バナー**: ストアの商品をパロディ広告で出す（「デスクトップが広がる！ 15インチCRT ¥19,800」「VACCINE 99 新発売」）。ブラック企業ネタの求人広告も（「アットホームな職場です」「やる気のある方歓迎・日当制」）。
- アクセスランキングの1位に、たまに**その夜の注目記事**が入る（読み逃し防止）。

## 6. データ・実装メモ
- `NewsArticleDefinition`（ScriptableObject）: ID, 表示する日（または条件）, カテゴリ, 見出し, 本文, 専門家コメント, 注目記事か, 画像。
- `NewsScreen`（新規）: 旧式ブラウザの枠（`RetroWindow` 流用）＋ポータルのレイアウト。`DocumentRenderer` で本文を表示（太字・色文字が使える）。
- 前夜の結果の記事は、`CareerRecord`（ENDINGS.md）の前夜の記録から選ぶ。
- 表示の流れ: `GameManager` で、DAY8 以降は `ShowClockIn()` の前に `ShowNews()` を挟む。
- 設定: ダイヤルアップ接続の演出をスキップするか（既定: 2回目以降は短縮）。

## 7. 決めること

3. 注目記事を読んだかどうかで、何か差をつけるか（今は差なし）

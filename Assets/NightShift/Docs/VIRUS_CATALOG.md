# NIGHT//SHIFT — ウイルスと被害イベント（案）

最終更新: 2026-10-04 ／ 状態: **検討中**

DAY9 以降、対応を誤ると社内にウイルスが入り込み、**ホラー調の被害イベント**が起きる。
舞台は 1999年の深夜のオフィス。文字化け・ブルースクリーン・CRT のノイズ・停電など、当時のパソコンの「壊れ方」を怖さに使う。

> すべて**ゲーム内の演出**。プレイヤーの実際の PC のファイルや OS には一切触れない（ブルースクリーンもゲーム画面の中で描くだけ）。

---

## 1. 設計の原則
1. **原因は必ずプレイヤーの対応ミス**（ストーリー上の最終夜を除く）。何もしていないのに突然壊れることはない。
2. **兆候 → 発症 → 拡大** の3段階。兆候の段階で気付いて対処すれば、被害は出ない。
3. **兆候は「気のせい」程度から**: 1文字だけ化ける、ビープ音が1回鳴る、カーソルが一瞬ずれる。気付ける人だけが気付く。
4. **怖さと難しさを分ける**: 演出は怖いが、ゲーム上の効果（見えない・使えない・時間を奪われる）は、はっきり分かる形にする。
5. **感染は夜をまたいで残る**。駆除しない限り、翌日の夜に続きが起きる。
6. **ジャンプスケアは控えめに**（1夜に1回まで）。基本はじわじわ来る怖さ。
7. **画面にメッセージの文字を出す演出はしない**（「見ている」などの言葉を浮かび上がらせない）。怖さは音・光・画像・動き・意味のない文字化けで出す。
8. **名前はすべて英語**（ウイルス名・ソフト名）。

### 表現の設定（タイトルの設定画面に追加）
| 設定 | 内容 |
|---|---|
| ホラー演出の強さ | 標準 ／ 控えめ（不気味な画像・ささやき声を出さない。ゲーム上の効果は同じ） |
| 点滅を減らす | 画面の激しい点滅・明滅を、ゆっくりした暗転に置き換える（光過敏性への配慮） |
| 急な大きな音 | オン ／ オフ |

- ブルースクリーン・ブラックアウト中でも、**Esc で設定・ポーズは必ず開ける**。

## 2. 感染の経路（トリガー）

| # | 経路 | 具体的な条件 | 起きるウイルス |
|---|---|---|---|
| A | **悪意ある接続を許可した** | 脅威の接続要求（T1, T6, T12 など）を許可した。接続先のサーバーで種類が決まる | ファイルサーバー → V2 ／ メールサーバー → V1 ／ 公開Web → V2 ／ 管理サーバー → V5 |
| B | **感染PCを放置した** | 感染した社員PC（T7）の兆候が出てから **ゲーム内30分** 以内に駆除・隔離しない | V3（周りのPCに広がる） |
| C | **自分で不審な添付ファイルを開いた** | 担当者宛てのメール（T5 など）の添付（例: `給与明細.txt.exe`）を開いた | V4（自分のワークステーション） |
| D | **リモート対応中に不審なファイルを実行した** | 社員PCのデスクトップにある見慣れないファイルを、リモート操作で開いた | V4（その社員PC → 自分の画面にも） |
| E | **自分のアカウントを奪われた** | T4 を許可した／T5 の偽フォームにパスワードを入力した | V7 |
| F | **ランサムウェアの前兆を放置した** | T11 の前兆から **ゲーム内30分** 以内に感染PCを隔離しない | V6（致命的 → ゲームオーバー GO2） |
| G | **前の夜の感染を駆除していない** | 感染したままのPC・サーバーが残っている状態で次の夜を迎えた | 同じウイルスの次の段階（拡大） |
| H | **ストーリー（最終局面）** | DAY28〜30。自律型攻撃AIの攻撃 | V8（被害の大きさは対応次第） |

- 経路 A〜F は、どれも**研修・マニュアルで教えた手順を守れば防げる**。
- 経路 G があるため、「その夜をやり過ごす」だけでは済まない（駆除までが仕事）。

## 3. ウイルス一覧

### V1 TINNITUS（いたずら型）— DAY9〜
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | 社員から「PCが夜中に勝手に鳴る」という問い合わせ。リモートで見ると、デスクトップのアイコンが**少しずつ画面の中央に寄っていく** | 問い合わせが増える |
| 発症 | 感染PCの壁紙が、**見知らぬ社員の証明写真**に変わる。社員名簿にその人はいない | 感染PCの社員が業務できない（その社員の接続要求が出なくなる → 正規の作業が止まる） |
| 拡大 | 件名も本文も空のメールが全社に広がる（添付は、その証明写真の画像だけ） | メールボックスに偽の添付メールが混ざる（開くと経路 C） |
- 駆除: リモートで不審なプロセスを終了 → 不審なファイルを削除。

### V2 GARBLE（ファイル書き換え型）— DAY17〜
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | ログビューアの1行だけ、文字が**1文字化けている**（`LOGIN 縺 OK`） | なし |
| 発症 | 感染したサーバーのログ・共有ファイルが、**気味の悪い文字列**に書き換わる（`縺ゅ＞縺�∴縺翫°縺阪￥縺代％…` ／ `繝ｻ繝ｻ繝ｻ譁�ｭ�繝ｻ…`）。意味のない文字の羅列が、画面いっぱいにびっしり並ぶ | そのサーバーのログが読めなくなる（脅威の手がかりが見えない） |
| 拡大 | 社員名簿の一部の社員の情報が化ける。顔写真の欄が**真っ黒な顔**になる。公開Web（T9）のトップページが文字化けの文章に改ざんされる | 化けた社員は照合できない（手動で人事に確認 → 時間がかかる）。公開Webの改ざんは会社の信用 −8 |
- 駆除: サーバー運用管理で不審プロセス停止 → **バックアップから復元**（ゲーム内15分かかる、その間そのサーバーは停止）。

### V3 NIGHTCRY（ワーム型・広がる）— DAY16〜
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | ネットワークモニターで、感染PCのノードが**心臓の鼓動のように**ゆっくり明滅する。遠くで**赤ん坊の泣き声のような**ノイズ | なし（T7 の兆候と同時） |
| 発症 | 03:33 になると、隣のPCのノードが1つずつ赤くなっていく。泣き声が増える | ゲーム内10分ごとに、同じ部署のPCが1台ずつ感染。そのたびに問い合わせが来る |
| 拡大 | ネットワークマップの線が**血管のように**脈打つ。全社の PC から一斉に「PCが泣いている」という問い合わせ | 問い合わせが一度に5〜8件。対応しきれないと会社の信用が下がる |
- 駆除: 感染PCを**隔離**（端末隔離ツール、または手動でネットワークを切る）→ 1台ずつ駆除。最初の1台を隔離すれば広がらない。

### V4 BLUESTONE（ブルースクリーン型）— DAY13〜
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | 画面の端が一瞬だけ青くちらつく。ディスクのカリカリ音が止まらない | なし |
| 発症 | **ブルースクリーン**。直前に、ディスクの音とファンの音が**同時にぴたりと止まる**。青い画面のまま、スピーカーから低いハム音が続く | その画面（メインモニター／サブモニター）が **再起動するまで使えない**（ゲーム内5分）。その間も時間は進み、要求は期限が近づく |
| 拡大 | 再起動の起動音（起動のメロディ）が**ゆっくり、低く歪んで**鳴る。ブルースクリーンが1夜に何度も起きる | 1夜に最大3回まで再発。サブモニターが落ちるとツールも止まる |
- 駆除: 再起動後、自分のワークステーションでウイルス検査（ゲーム内5分）。社員PCの場合はリモートで駆除。
- 経路 C（自分で添付を開いた）の場合は**メインモニター**が落ちるため、最も痛い。

### V5 REDACT（ブラックアウト型）— DAY19〜
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | 管理サーバーのログに、深夜なのに**無停電電源装置（UPS）の設定変更**の記録。オフィスの蛍光灯が**一度だけ瞬く** | なし（T10 管理者アカウントの乗っ取りと連動） |
| 発症 | **ブラックアウト**。フロアの電源が落ち、すべてのモニターが真っ暗に。非常灯の緑の光だけ。暗闇の中で、**電源の切れたはずのCRTが、高い「ジーッ」という音とともにかすかに光っている**。サーバールームのファンが止まる音 | 画面が **ゲーム内10分間** 何も見えない（操作できない）。復旧後、サーバーを決まった順番で起動し直す必要がある（認証 → ファイル → メール → 公開Web） |
| 拡大 | 復旧したはずのモニターの1台に、**主人公の後ろ姿**が映っている（監視カメラの映像） | 2回目のブラックアウト。起動の順番を間違えるとサービスが起動しない |
- 防ぎ方: 兆候（UPSの設定変更）を見つけたら、**管理者アカウントを一時停止**（ユーザー管理）。
- 会社の信用: ブラックアウト1回につき −5（業務サーバーの停止）。
- 夜が終わるまで管理者アカウントを止めなかった場合は **ゲームオーバー（GO2 重大インシデント）**（ENDINGS.md の「致命的な脅威」T10）。

### V6 BRIAR ROSE（ランサムウェア）— DAY20〜 ★致命的
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | ログに、1台の端末からの `FILE WRITE` が連続（T11）。ファイル名の末尾が `.briar` に変わり始める | 30分の猶予が始まる（画面には出ない） |
| 発症 | 共有フォルダのファイルが次々と `.briar` に。各フォルダに `README.briar` が置かれ、開くと**オルゴールの子守唄が流れるだけ**（文章は出ない）。社員PCの壁紙が**眠る少女の絵**に変わる | 隔離が間に合わなければ全社に広がる |
| 拡大 | 全社のPCに同じ壁紙。オルゴールの音。画面の時計が **06:00 に向けて逆回り**に動く | **ゲームオーバー（GO2 重大インシデント）** |
- 防ぎ方: 兆候から30分以内に、`FILE WRITE` を出している端末を**隔離**（最優先）。

### V7 DOPPELGANGER（アカウント複製型）— DAY14〜
| 段階 | 演出（ホラー） | ゲーム上の効果 |
|---|---|---|
| 兆候 | 自分のメールボックスに、**自分から自分宛て**のメールが届く（件名なし・本文は今の時刻だけ） | なし |
| 発症 | 接続監視に、**自分のID**からの接続要求（T4）。サブモニターの上を、**もう1つのマウスカーソル**がゆっくり動いている | もう1つのカーソルが、サブモニターのツールを勝手に閉じる・設定を変える |
| 拡大 | もう1つのカーソルが、メインモニターの[許可]ボタンの上で止まる | 2回目の被害で **ゲームオーバー（GO3 踏み台）** |
- 防ぎ方: 自分のIDの要求は拒否 → パスワード変更。研修でのパスワードが弱い・付箋ありだと発生しやすい。

### V8 DAYBREAK（自律型攻撃AI）— DAY28〜30（ストーリー）
- 自律型攻撃AIが V1〜V7 の手口を**組み合わせて**使ってくる。拒否されると別の手口に切り替える。
- 演出: 夜が更けるほど、画面のあちこちに**前任者の痕跡**（ログに残る前任者の社員番号、もう1つのカーソルの動き方の癖、V3 と同じ泣き声のノイズ）が増える。
- 最終夜の結果（完全防衛／一部被害／重大インシデント）で本編エンドが決まる（ENDINGS.md）。

## 5. ウイルス対策ソフト（VACCINE 99）との関係
| ウイルス | 手作業での対処 | VACCINE 99 |
|---|---|---|
| V1 TINNITUS | リモートでプロセス終了・ファイル削除 | Clientで検出・駆除 |
| V2 GARBLE | サーバー運用管理で停止 → バックアップから復元 | Serverで検出・駆除（化けたファイルは復元が必要） |
| V3 NIGHTCRY | 隔離 → 1台ずつ駆除 | Clientで1台ずつ駆除（隔離は別に必要） |
| V4 BLUESTONE | 再起動 → 手作業で検査 | 常駐監視で、感染した添付を開く前に止める |
| V5 REDACT | 管理者アカウントの一時停止 | **検出できない** |
| V6 BRIAR ROSE | 30分以内に隔離 | Serverで兆候の段階なら検出（定義ファイルの更新が必要） |
| V7 DOPPELGANGER | 自分のIDの要求を拒否 → パスワード変更 | **検出できない** |
| V8 DAYBREAK | 総力戦 | **検出できない** |
- 手作業でも必ず対処できる（ソフトは時間を短くする・見落としを減らすためのもの）。

## 7. 実装メモ
- `MalwareDefinition`（ScriptableObject）: ID, 名前, 解禁日, 経路, 段階ごとの演出（テキスト・画像・音）と効果, 駆除の手順。
- `InfectionState`（保存・夜をまたぐ）: どのPC・サーバーが、どのウイルスの、どの段階か。既存の `MalwareState`（リモートPC）を拡張。
- `HorrorFx`（新規）: 画面のノイズ・ちらつき・文字化け（表示テキストを化けた文字に置き換える関数）・偽のブルースクリーン・ブラックアウト・もう1つのカーソル。**ホラー演出の強さ／点滅を減らす**の設定に従う。
- 文字化けは、実際の文字コードの取り違え（Shift_JIS ↔ UTF-8 など）で作った文字列を使い、それっぽさを出す。**元の文は意味のない文字列にして、化けた文字から言葉が読めないようにする**。

## 2. 何があったか（背景）
1. 1996年秋、夜間IT運用担当として入社。日当制・罰金・機材自腹という、主人公と同じ条件。
2. 一人で夜間の全業務を回しながら、マニュアルや手順書を整え、問題点を何度も上長に報告した（すべて握りつぶされる）。
3. 1998年春、深夜の勤務中に倒れる（ゲームオーバー GO4「過労で倒れる」と同じ状況）。
4. 入院中に「試用期間満了」として契約を打ち切られる。未払いの深夜割増も、罰金の返還もなし。
5. 退職後、会社は**前任者のアカウントを無効にし忘れた**（脅威 T6「退職者アカウントの悪用」の原因。ITサポートの A13／Y11 と同じ問題）。
6. 前任者は、会社のシステムの弱点を誰よりも知っていた。それを使って、自分の代わりに会社を攻撃し続ける**自律型攻撃AI**を作る。
7. 1998年5月、主人公が後任として入社（DAY1）。

### 動機（はっきり言い切らない）
- 会社への復讐、違法な働かせ方の告発、「同じ目に遭う後任を出したくない」という思いが**混ざっている**。
- 攻撃の狙いは、社員個人ではなく**会社の経営陣とその記録**（勤務記録の改ざん、給与の不正など）。ただし攻撃の巻き添えで、普通の社員や主人公も被害を受ける。
- 主人公のことは、着任した日から**ログ越しに見ている**。

## 4. 付箋（手がかり1）の中身
- ワークステーションの裏に貼られていた、前任者の手書きのメモ。
- 内容（案）: 「夜は長い。全部を一度に見ようとしないこと」「このPCのパスワードは付箋に書かないこと」。
  - 研修で**パスワードを付箋に書いたプレイヤー**には、皮肉として刺さる。
- 業務のヒントにもなる（同時発生の夜の心構え）。

## 5. END3「真夜中の答え合わせ」での対話（概要）
- 最終夜、攻撃元を追跡すると、社内チャットのような画面で前任者とつながる。
- 前任者は、主人公の30日間を知っている（何回罰金を取られたか、何回残業したか、どのツールを自腹で買ったか）。
- 会話の流れ（案）:
  1. 前任者: 「この夜勤のこと、ここまで続けられた人は初めて」
  2. 主人公の記録に合わせた一言（罰金が多い／残業が多い／AIに頼った など）
  3. 前任者が、攻撃の目的（会社の不正の記録を外に出すこと）を明かす
  4. 主人公の選択: **［通報する］** ／ **［証拠を労基署に持っていく］**
     - 通報: 前任者は逮捕される。会社の不正も裁判で明るみに出る。主人公は夜勤を辞める
     - 労基署: 前任者の集めた証拠と主人公の給与明細で、会社に是正勧告。前任者は姿を消す
- どちらを選んでも、最後に夜が明ける（タイトル「NIGHT//SHIFT」の終わり）。

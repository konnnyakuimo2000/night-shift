# NIGHT//SHIFT — 業務効率化ツール一覧（案）

最終更新: 2026-10-04 ／ 状態: **検討中**

ストア（社内購買システム、DAY8〜）で購入する機材・ツールの一覧。

## 原則
1. **手間を減らすだけ。判断はしない。** 許可/拒否・危険かどうかを自動で表示しない（「○×の比較結果」「危険マーク」は出さない）。
   **例外は3つ**: ①「自動審査ツール」— プレイヤー自身が決めた条件をすべて満たす**簡単な要求だけ**を自動で許可する（下記 A）。
   ②「サイバー防御AI」（最終盤）— 持っているツールを使って**判断の提案・代行**ができる。ただし**トークン制限があり高コスト**で、間違えることもある（下記 I）。
   ③「ウイルス対策ソフト」— **既知のウイルスだけ**を検出・駆除する。新しいウイルスは定義ファイルを更新しないと見つけられない（下記 J）。
2. **研修で覚えた手順を短くする**ものが中心（毎回の検索・画面の行き来・ログの目視を楽にする）。
3. **脅威の解禁に合わせて買えるようになる**（その週に役立つツールが店頭に並ぶ）。
4. 効果は「機能の解放」（`Features`）として付与する → 既存の `Unlocked()` の仕組みでそのまま有効/無効を切り替えられる。
5. 購入した次のシフトから使える。
6. **ツールはサブモニター（担当者用ワークステーション）にインストールされるアプリ**。サブモニターのデスクトップ／スタートメニューから起動し、**起動している間だけ効果がある**。サブモニターの画面は社員PCと同じ Windows 風の UI。
7. **サブモニターが無いとツールは使えない**（機材の「サブモニター1台目」が前提）。メインモニターの操作と連動する（選んだ要求・選んだログ行などに合わせて表示が変わる）。

## 予算の目安（厳しめ・1990年代末の物価）
- 会社は**ブラック企業**。日当 ¥5,000（深夜手当込み）、罰金は天引き、**業務に使う機材・ツールも自腹**（社内購買システムで買い、給与から精算）。給与の詳細は DAY8_Requirements.md の「給与体系」。
- 30日間の手取りの合計 ≒ **¥14〜16万**（研修7夜 ≒ ¥2.5万、本番23夜 ≒ ¥11〜14万）

### 自動審査ツールの仕様
- **自動許可の条件**（チェックボックスで ON/OFF。すべて満たした要求だけ自動許可）:
  | 条件 | 選べるようになる日 |
  |---|---|
  | 社員として登録されている | DAY10（購入時から） |
  | 自分の登録端末からの接続 | DAY10 |
  | 社内からの接続 | DAY10（**常に必須・外せない**） |
  | 必要な権限が ○ | DAY10 |
  | 普段使うシステムへの接続 | DAY10 |
  | 勤務中の社員 | DAY10 |
  | 接続元IPが登録端末のIPと一致 | DAY10（DAY9 のルールに対応） |
  | 在籍中（退職・休職でない） | DAY12 |
- **自動では許可しないもの**（条件に関係なく手動）: 社外からの接続、管理系サーバー（ADMIN-SRV01 等）、VPN接続、セキュリティ警告が付いた要求。
- **拒否は自動ではしない**（違反の判断は常にプレイヤー）。
- 自動許可した要求は一覧・ログに `AUTO-ALLOWED` と表示。処理時間はほぼ0（応答時間の評価が上がる）。
- **責任はプレイヤー**: 自動許可した要求が不正だった場合、手動で許可した場合と同じく減点・減給。
- **攻撃者は自動許可の穴を狙う**:
  - 条件を少なくするほど多くの要求が自動で片付くが、なりすまし（T1: IPの照合を外している）・退勤中の社員（T2: 勤務中を外している）が通ってしまう。
  - 第4週の攻撃支援AI（T12）は「普段の行動」まで真似るため、全条件を ON にしても通る要求を混ぜてくる → 自動許可のログを後から見直す必要が出てくる。
- 有効/無効はいつでも切り替えられる。サブモニターで起動中のみ動作（他のツールと同じ）。

### 残業（缶コーヒー）の仕様
- 06:00 になった時に缶コーヒーを持っていると、「**残業する（缶コーヒーを1本飲む）／ 退勤する**」を選べる。
- 残業中（06:00〜06:30）:
  - **新しいイベントは来ない**（朝の出社前で静か）。
  - 残っている**接続要求は期限切れにならない**／**未解決の問い合わせ（リモート対応）を続けられる**。
  - **残業代は出ない（サービス残業）**。缶コーヒーも自腹。
- すべて片付けるか 06:30 になったら業務終了。
- 狙い: 同時発生で抱えきれなかった仕事を片付け、**期限切れ・未解決の罰金（1件 ¥200〜¥300）を避ける**ための保険。¥120 の缶コーヒーで罰金1件分を防げれば元が取れる。何も残っていなければ飲む必要はない。


## I. サイバー防御AI（最終盤）
| ID | 品名 | 効果 | 解禁 | 価格 |
|---|---|---|---|---|
| `AI_CYBER_ASSISTANT` | **サイバー防御AI「SOC-AI」** | 担当者用ワークステーションで動くAIアシスタント。**持っているツールをプラグインとして接続**し、それらを使って調査・提案・代行を行う | DAY25 | ¥49,800（導入費） |
| `AI_TOKEN_PACK` | **追加トークン** | その夜に使えるトークンを **+20,000** | DAY25 | ¥2,980 |

### 仕様
- **プラグイン方式**: AI 単体では何もできない。**購入済みのツールを接続した分だけ**できることが増える。

  | 接続するツール | AI ができること | 消費トークン（1回） |
  |---|---|---|
  | （なし） | 業務メール・マニュアルの要約、質問への回答 | 500 |
  | 社員情報パネル | 要求と社員情報を照合し「合わない項目」を指摘 | 1,500 |
  | 自動審査ツール | 自動許可の条件では判断できない要求を審査し、**許可/拒否を提案**（承認するとそのまま実行） | 3,000 |
  | ログ解析 | ログ全体から「同じ接続元の連続失敗」「大量アクセス」を探して報告 | 4,000 |
  | 遮断コンソール | 不審な接続元をまとめて**遮断する提案**（承認で実行） | 2,500 |
  | メール差出人チェッカー | 受信メールの差出人・リンクを調べ、フィッシングの疑いを指摘 | 1,500 |
  | VACCINE 99（Client／Server） | 検査の対象と順番を決めて自動で検査し、結果を報告（定義ファイルの限界は同じ） | 2,000 |
  | リモート診断キット／端末隔離ツール | 問い合わせのPCを診断し、原因と対処を提案／感染PCの**隔離を提案** | 5,000 |
  | サーバー監視ダッシュボード | 全サーバーの異常（見慣れないプロセス・通信量の急増）を報告 | 6,000 |
  | 相関タイムライン | 一連の攻撃の流れ（同じ攻撃者の別経路）をまとめて報告 | 8,000 |

- **トークン制限**: 1夜に使えるのは **30,000 トークン**（ライセンスに含まれる分）。足りなければ「追加トークン」（¥2,980／+20,000）を買う。日当の半分以上が飛ぶ。使い切ると AI はその夜は停止。
  - 目安: 1夜の全要求を AI に審査させると 6〜10万トークン必要 → **全部は任せられない**。難しい要求・大事な場面に絞って使う。
- **提案 → 承認**: AI は「提案」を出し、プレイヤーが [承認] すると実行される。**「全自動モード」**（承認なしで実行）も選べるが、トークン消費 1.5倍。
- **AI も間違える**:
  - 正答率はおよそ 90%。理由（どの項目を見たか）が表示されるので、プレイヤーが確かめられる。
  - 実行結果の責任はプレイヤー（他のツールと同じ）。
  - **攻撃者は AI を騙しにくる**: 自律型攻撃AI（T14）や、要求の備考欄に AI 向けの偽の指示を書き込む手口（T15）で、AI の提案を誤らせる。
- 狙い: 最終盤の量と速さには人間だけでは追いつけない → AI に頼りたくなるが、**お金（導入費＋追加トークン）と、AI を信じすぎる危険**の両方を天秤にかける。


## J. ウイルス対策（DAY10〜）
| ID | ツール（アプリ） | 効果 | 解禁 | 価格 | 役立つウイルス |
|---|---|---|---|---|---|
| `TOOL_VACCINE` | **VACCINE 99 Client** | 担当者用ワークステーションと、リモート接続中の社員PCを検査・駆除。**常駐監視**で、自分のワークステーションで感染ファイルを開こうとすると警告して止める | DAY10 | ¥9,800 | V1, V3, V4 |
| `TOOL_VACCINE_SERVER` | **VACCINE 99 Server** | 社内サーバーとバックアップを検査・駆除（Clientが前提） | DAY17 | ¥19,800 | V2, V6 |
| `ITEM_VACCINE_UPDATE` | **定義ファイル更新** | 最新のウイルス定義に更新（その時点までに出たウイルスを検出できるようになる） | DAY10〜 | ¥1,000／回 | — |

### 仕様
- **検査**: サブモニターのVACCINE 99 から実行。
  - 自分のワークステーション: ゲーム内5分
  - 社員PC（リモート接続中のみ）: ゲーム内2分
  - サーバー（Server）: 1台につきゲーム内5分
  - 検査中もゲームは進み、そのPC・サーバーは少し遅くなる。
- **検出できるのは「定義ファイルに載っているウイルス」だけ**。
  - 購入した時点の定義ファイルが付いている。その後に解禁されたウイルスは、**定義ファイルを更新しないと見つからない**（更新は1回 ¥1,000。自腹）。
  - 兆候の段階でも、検査すれば見つかる（発症前に止められる）。
- **駆除**: 見つけたウイルスをボタン1つで駆除。ただし**壊されたものは戻らない**（V2 で化けたファイルはバックアップからの復元が必要、V6 で暗号化されたファイルは戻らない）。
- **常駐監視**（Client）: 自分のワークステーションで感染ファイル（経路 C の添付など）を開こうとすると「ウイルスを検出しました」と警告して止める。**定義ファイルに載っているものだけ**。
- **検出できないもの**:
  | ウイルス | 理由 |
  |---|---|
  | V5 REDACT | ウイルスではなく、乗っ取られた管理者アカウントによる設定変更 |
  | V7 DOPPELGANGER | ウイルスではなく、奪われたアカウントによる不正利用 |
  | V8 DAYBREAK | 自律型攻撃AIが手口をその場で作り替えるため、定義ファイルに載らない |
  - 新種の亜種（第4週の攻撃支援AIが作るもの）は、更新した直後でも**半分ほどしか**見つからない。
- **ホラー演出**: 定義ファイルが古いまま検査すると「ウイルスは見つかりませんでした」と出る。その直後に画面の端が一瞬だけ化ける（安心させてから裏切る）。
- **偽のウイルス対策ソフト**: V1 の拡大段階で、社員PCに「ウイルスを検出しました！今すぐ駆除」という**偽の警告画面**が出ることがある。VACCINE 99 の画面と見比べて見抜く（押すと経路 D）。
